Privacy Policy — Instegram Content Manager

Last updated: 2026-08-02

Instegram Content Manager is a personal-use tool that connects to a single Instagram Professional account via the Instagram API with Instagram Login, for the purpose of publishing content (photos, Reels, Stories) and managing replies to comments and direct messages on that same account.

What data is accessed

  • The connected Instagram account's own posted media and captions.
  • Comments and direct messages sent to the connected account, solely to display them for drafting a reply.
  • Basic account metrics (follower count, post counts) for the account owner's own reference.

What data is NOT accessed

This tool does not access any Instagram account other than the one account it is explicitly connected to. It does not scrape, store, or process data belonging to other Instagram users beyond the text of comments/messages they send to the connected account.

How data is stored

All data (access tokens, comment/message content, drafted replies) is stored locally on the account owner's own device. Nothing is sent to or stored by any third-party server other than Meta's own Instagram API, which is required to publish content and retrieve comments/messages.

How data is used

Comment and message content is used only to let the account owner (or their designated assistant) draft and send a reply. It is not used for advertising, resold, or shared with any other party.

Data retention and deletion

Data is retained locally for as long as the tool is in use. The account owner can delete all locally stored data at any time by removing the tool's configuration files. Disconnecting the app removes its access to the Instagram account via standard Instagram/Meta account settings.

Contact

This is a single-account personal tool with no public users beyond its owner. Questions can be directed to the GitHub repository this policy is hosted in.
